# Участие в разработке

[English](CONTRIBUTING.en.md)

1. Создайте ветку от `main` и внесите небольшое, законченное изменение.
2. Добавьте содержательные тесты для изменившихся границ доступа или сетевого поведения.
3. Обновите русскую и английскую документацию, если меняется использование инструмента.
4. Проверьте публикуемые файлы: `python3 scripts/check_public_files.py`.
5. Соберите образ и запустите тесты по README. Для тестов личный аккаунт MAX не нужен.
6. В pull request опишите проблему, поведение после изменения и выполненные проверки.

Не добавляйте реальные ID пользователей, номера телефонов, QR, сессии, подписанные ссылки, токены, локальные дампы или содержимое переписки. Не вызывайте реальные отправки в автоматических тестах. Любой ручной тест отправки требует явного поручения владельца аккаунта и конкретного получателя.

Код MCP-обёртки находится в `app/server.py`; работа с файлами — в `app/attachments.py`; stdio-прокси — в `app/bridge.py`; подготовка файлов на хосте — в `scripts/transfer.py`.
